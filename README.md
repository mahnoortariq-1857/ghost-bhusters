This game is called "ghost bhusters" (ghostship)
this is spooky halloween themed mini game built using p5.js.Its simple to play!Click on the moving ghost as much as possible to score points before time runs out!
How its built: Its built using javaScript andP5.js library.It feautures a custom game state system along with random movement,a timer, and score tracking.
Play instructions: 1-open the game using p5.js web editor using the link
                   2-click on the run button
                   3-click on the game screen to start the game.
                   4-click on the ghost as many time during the 30s duration to score points.
